# eletrocircular

BI local da operação EletroCircular/PNRS.

## Rodar

```bash
python3 meta_api/local_dashboard.py
```

Abra:

```text
http://127.0.0.1:8788
```

## Dados

O repositório inclui apenas dados agregados e relatórios sem contatos pessoais. A base bruta de leads com emails, telefones e CNPJs não deve ser versionada.

Veja detalhes em [meta_api/README.md](meta_api/README.md).
